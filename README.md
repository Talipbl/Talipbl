## 💫 About Me

I'm a **.NET Backend Developer** based in Istanbul, Türkiye, working at **Atak Domain**, where I build the backend systems behind domain registration and management.

- 🌐 **What I build:** Registry integrations over **EPP**, domain & DNS provisioning services, and the background workers that keep them in sync.
- 🧩 **How I build it:** Modular **.NET** services with **DDD** and **Clean Architecture** (on **Volo.ABP**), so complex business rules stay testable and easy to change.
- ⚡ **Under the hood:** Message-driven workflows with **RabbitMQ**, caching with **Redis**, and search with **Elasticsearch**.
- 🎯 **Currently exploring:** Resilient distributed workflows (retries, idempotency, outbox) and SQL query optimization.
